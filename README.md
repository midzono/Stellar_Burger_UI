# Stellar Burgers — UI autotests

## Описание проекта

Проект содержит UI-автотесты веб-приложения Stellar Burgers, написанные на Python с использованием Selenium и pytest.

В проекте применяется паттерн Page Object для разделения тестов, локаторов и методов взаимодействия с интерфейсом.

## Технологии

* Python
* pytest
* Selenium WebDriver
* Allure Pytest
* Google Chrome
* Mozilla Firefox

## Структура проекта

* `conftest.py` — фикстура запуска браузеров.
* `locators.py` — локаторы элементов интерфейса.
* `pages/` — Page Object классы.
* `tests/` — UI-автотесты.
* `requirements.txt` — зависимости проекта.
* `allure-report/` — HTML-отчёт Allure.

## Установка

Клонируйте репозиторий и перейдите в папку проекта.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Для запуска тестов должны быть установлены Google Chrome и Mozilla Firefox.

## Запуск тестов

Запуск всех тестов:

```bash
python -m pytest
```

Запуск тестов с формированием результатов Allure:

```bash
python -m pytest --alluredir=allure-results
```

## Формирование Allure-отчёта

После запуска тестов выполните:

```bash
allure generate allure-results --clean -o allure-report
```

Для открытия сформированного отчёта:

```bash
allure open allure-report
```

## Покрытие тестами

Проверяются:

* переходы между разделами «Конструктор» и «Лента заказов»;
* открытие и закрытие окна с деталями ингредиента;
* увеличение счётчика ингредиента при добавлении в заказ;
* отображение счётчиков заказов;
* раздел заказов в работе.

Тесты настроены на запуск в Chrome и Firefox.

## Примечание

При недоступности тестового приложения тесты могут завершаться ошибками соединения. Результаты запуска сохраняются для формирования отчёта Allure.
